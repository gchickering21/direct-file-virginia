The proof: what the checks found

The site makes three claims: that fifty households compute the same Form 760 lines as an independent model of the rules written from the Code of Virginia rather than from the XML; that every Virginia screen, in both languages, passes an accessibility scan; and that the engine's own test suite pins the four demo households and the invariants of any return this module can produce. This page is the evidence, produced by the checks themselves when this copy of the site was built.

Run them yourself

With the site running locally (make dev or make demo): make cases drives every household through the real pages in a browser and compares each line; make a11y runs axe-core over every Virginia route; make test runs the ScalaTest suite. make proof does all three against a built site and writes what this page reads.
