Commonwealth of Virginia

Virginia State Return

A Virginia state return, computed from the federal one, on the IRS's published code

The IRS built Direct File, published its source into the public domain, and suspended it in 2025. This prototype adds a Virginia return (Form 760) on top of that code. Most of the return is already filled in from the federal answers; the filer corrects what is wrong, answers four questions nobody reports for them, and sees the return.

Pick a household below. Each opens on the Virginia intro with that person's federal return already answered. Click Next through the screens, or jump straight to the return. Opening a household replaces whatever is in this browser tab's session.

What to look for

  1. What Virginia already has. The second screen groups what is known by where it came from: Virginia Tax's own records, the W-2 the employer filed, the federal return. Nothing on it was typed.
  2. A correction, and what it changed. Say something is wrong, change a W-2, and the next screen shows what moved and by how much.
  3. Four questions, then the return. Locality (proposed from the ZIP code), military pay, Commonwealth Savers, untaxed purchases. Then Form 760 line by line, with a Change link on every answer and a "why this number" under the lines that need one.
  4. The same in Spanish. Every Virginia screen is translated: Riley's return, en español.

Look under the hood

  • Browse All: every screen in the flow, federal and Virginia, with the condition that shows or hides it. Open the list (built into the developer site; a plain production build leaves it out).
  • The fact dictionary: every rule the engine runs, federal and Virginia, as one XML file. The Virginia facts are the ones whose paths begin with /va. Open it.
  • The Rules Workbench: Form 760 line by line with the statute beside each, where policy staff change a figure or a rule in plain language and watch worked examples rerun. It runs on your own machine: make workbench, then http://localhost:3011.
  • The federal return: the port of Direct File's own interview, untouched. Start from the first federal screen.
  • The code and the write-up: github.com/gchickering21/direct-file-virginia. The architecture page there has the two diagrams; the one-page brief has the argument.

How it works, in three sentences

The rules are XML facts in the IRS's Fact Graph, compiled to JavaScript and run entirely in this browser: no server holds your answers, and nothing leaves the page. The screens are the IRS's Form Builder turning Flow XML into static HTML, one question per page. Virginia is ten small rule modules and fourteen screens beside the federal ones, reading only the facts the federal return already exports to states, with every rule naming its section of the Virginia Code.
