Making the Virginia screens look like Virginia's

Mockups for the Virginia section of the port. Today a Virginia filer stays under the IRS header, in IRS blue, with the federal progress bar, so the screens look like one more federal step. The idea in all of these: the federal return hands off to Virginia. From that point Virginia's colours, Virginia's voice and Virginia's own records take over. Each screen uses the Virginia Demo 1 household (Riley Rappahannock, fictional). The flower emblem is a placeholder drawn for these mockups, not the seal or Virginia Tax's logo.

Your Virginia return

The least work: one header fragment and an accent colour. Weaker as a signal; the page still reads as federal.

Why A

  • The IRS mark and the U.S. government banner both leave. A filer who sees them is told this is the IRS's form. Virginia's section is Virginia's to sign for.
  • The right side of the header confirms the handoff: "Federal return accepted by the IRS ✓". It answers "where did my federal return go?"
  • The orange-tinted strip makes the demonstration notice permanent and part of the chrome, so it no longer has to start the first paragraph of each screen.
  • The 25-segment federal bar becomes a five-step Virginia track. "Federal return" is the first step, already finished, in grey.

To build

  • The header lives in Form Builder's templates/page.html. Add a th:if on currentPageRoute starting /your-taxes/virginia/ and a fragments/va-header.html override in this app, the way usa-step-indicator.html is already overridden.
  • Put a body.va class on the same condition, then add styles/components/virginia.css.

What changed

  • The order is reversed: Virginia's own records first. That is the state-side half of "the government already knows", and it is what makes the screen feel like Virginia's, not a federal echo.
  • Each source has a badge. A filer can tell at a glance who reported what.

Trade-off

  • Taxable Social Security is $0 for most filers. Hide that row when it is $0 instead of showing a blank.

  • Navy carries the page and orange only punctuates it: the rule under the header, the current step, the edge of Virginia's own card, the amount due. White page, no tinted backgrounds. The dogwood is the state flower, a generic state symbol; neither borrows Virginia Tax's identity. Swap in the real marks if Virginia Tax supplies them.
  • Orange is never used for text on white, and white text never sits on orange: both fail WCAG AA at body size. Orange on navy passes (about 4.7:1), so the amount-due date can be orange. Buttons are navy with an orange underline. Re-run scripts/virginia-a11y.cjs after building.
  • Headings are set in a serif (Merriweather, which USWDS already ships), against USWDS's sans-serif for federal screens. The change in typeface tells the filer they are on a different page.
  • USWDS components stay underneath: combo box, radios, tables, focus rings. Only tokens and chrome change. Spanish and accessibility work carry over.

Suggested order

  • 1. Header, track and colours (option A): the biggest change for the least work.
  • 2. Result screen: the moment people remember.
  • 3. Handoff and source cards.
  • 4. Locality card, sign step.
